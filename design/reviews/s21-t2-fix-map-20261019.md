## Recommended Single Token/Scale Fix (Prefer Over Per-Page Overrides)

Per `docs/spec/10-DESIGN-SYSTEM-WHITELABEL.md:74-85`, define the type-scale CSS custom properties once in `:root` and `@media (max-width: 700px)` in `src/app/globals.css:8-50` and bind semantic elements/classes to them:

```css
:root {
	/* Selected Type Scale (docs/spec/10-DESIGN-SYSTEM-WHITELABEL.md:74-85) */
	--fs-page-title: 1.75rem;      /* 28px desktop */
	--lh-page-title: 2.25rem;      /* 36px desktop */
	--fs-price: 1.5rem;            /* 24px desktop */
	--lh-price: 2rem;              /* 32px desktop */
	--fs-section-heading: 1.25rem; /* 20px desktop & mobile */
	--lh-section-heading: 1.75rem; /* 28px desktop & mobile */
	--fs-card-heading: 1.125rem;   /* 18px desktop & mobile */
	--lh-card-heading: 1.625rem;   /* 26px desktop & mobile */
}
@media (max-width: 700px) {
	:root {
		--fs-page-title: 1.5rem;   /* 24px mobile */
		--lh-page-title: 2rem;     /* 32px mobile */
		--fs-price: 1.25rem;       /* 20px mobile */
		--lh-price: 1.75rem;       /* 28px mobile */
	}
}
```

Then:
- `h1` uses `font-size: var(--fs-page-title); line-height: var(--lh-page-title); font-weight: 600; letter-spacing: normal;` (no per-page `h1` size overrides).
- `h2` uses `font-size: var(--fs-section-heading); line-height: var(--lh-section-heading); font-weight: 600; letter-spacing: normal;` (removing the scattered `.buying-note h2`, `.shopping-help h2`, `.help-main h2`, `.empty-state h2`, `.section-heading h2` font-size overrides).
- `.product-price`, `.detail-price`, and `.price-statement strong` use `font-size: var(--fs-price); line-height: var(--lh-price); font-weight: 600; letter-spacing: normal;` (removing duplicate mobile `1.5rem` declarations at `globals.css:677,740,1058`).
